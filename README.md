Bookstore Management System

A desktop application built with Python, Tkinter, and SQLite for managing bookstore inventory and sales records.

## Features
* **Inventory Management**: Add, update, view, and delete book records (Title, Author, Year, ISBN).
* **Search Filter**: Search books easily by title, author, year, or ISBN.
* **Database Integration**: Lightweight SQLite integration for data persistence.
* **User-Friendly GUI**: Clean desktop interface built using Python's native Tkinter framework.

## Tech Stack
* **Language**: Python
* **GUI Framework**: Tkinter
* **Database**: SQLite3
